# Source Quality Rubric

Use this rubric when source choice affects confidence or when sources disagree.

## Default Ranking

1. Primary sources: official docs, vendor pricing pages, standards, release notes, filings, original studies.
2. Reputable secondary sources: strong summaries that accurately cite primary material.
3. Aggregators or commentary: use only when better sources are unavailable, and label their role clearly.

## Selection Rules

- Prefer the most direct source for the claim.
- Prefer newer sources when the topic changes quickly.
- Prefer jurisdiction- or region-specific sources when location matters.
- Prefer sources with clear authorship and update history when authority matters.

## Conflict Handling

- Do not merge conflicting claims into a false consensus.
- State which sources disagree and what each source says.
- If one source is stronger, say why: newer, primary, narrower scope, or more authoritative.

## Confidence Cues

Higher confidence:

- multiple independent sources agree,
- a primary source directly supports the claim,
- the source is current for the topic.

Lower confidence:

- only summaries are available,
- the source is stale,
- scope is unclear,
- or the claim requires inference across multiple documents.
