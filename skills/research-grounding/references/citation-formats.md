# Citation Formats

Use the host format exactly. Do not improvise a different citation style.

## Inline Citation

Attach citations directly to the sentence or bullet they support.

Example:

- Bun 1.2 adds feature X and deprecates feature Y. [Source A]

## Footnotes

Use when the host wants cleaner prose with references collected at the end.

Example:

Text with supported claim.[1]

[1] Source title or URL

## Memo Style

Use short sections with citations attached to the key factual statements in each section.

Example:

## Findings

- Vendor A raised entry pricing in Q1 2026. [Pricing page]
- Vendor B still includes the same feature in the base tier. [Pricing page]

## Rules

- Cite only sources retrieved in the current workflow.
- If quoting, quote exactly and only when the wording matters.
- If the host requires URLs, include URLs. If the host requires labels, use labels.
