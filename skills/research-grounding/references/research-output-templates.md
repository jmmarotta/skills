# Research Output Templates

Use these as defaults when the user does not specify a format.

## Short Answer

1. Direct answer
2. Key evidence
3. Conflicts or uncertainty
4. Sources

Use for quick factual lookups or compact synthesis.

## Comparison

1. Recommendation or bottom line
2. Option A
3. Option B
4. Tradeoffs
5. Sources

Use when comparing vendors, tools, APIs, or policies.

## Risk Review

1. Main risks
2. Evidence
3. Missing information
4. Recommended next step
5. Sources

Use when the user wants concerns, blockers, or decision support.

## Memo

1. Conclusion
2. Findings
3. Conflicts or uncertainty
4. Open questions
5. Sources

Use when the user wants a polished brief instead of a short answer.
